# Septic Repair Leads & Scraper Engine (All US States)

Автоматизированный парсер и база данных целевых лидов по нише **Septic Repair / Ремонт септиков** по всем штатам США из Google Maps.

---

- **Охват:** 293 ключевых города во всех штатах США (представлены 49 штатов).
- **Квалифицировано целевых компаний:** **597 уникальных лидов**.
- **Загружено фото высокого разрешения:** **1 883 изображения**.

## 🔍 Критерии квалификации лидов

1. **Рейтинг в Google Maps:** строго от **4.6** до **5.0** звезд.
2. **Количество отзывов:** строго от **25** до **200** отзывов (подтвержденная репутация, но без корпоративной недоступности).
3. **Статус сайта компании:**
   - **Сайт отсутствует в карточке Google Maps** (`NO_WEBSITE`) — 264 компании.
   - **Сайт не открывается / сброс соединения** (`ECONNRESET`) — 118 компаний.
   - **Сайт не открывается / таймаут** (`TIMEOUT`) — 97 компаний.
   - **Страница Facebook вместо отдельного сайта** (`FACEBOOK`) — 27 компаний.
   - **Ошибка 404 Not Found** — 19 компаний.
   - **Истёк или недействителен SSL-сертификат** — 17 компаний.
   - **Ошибка DNS / домен не найден** — 13 компаний.
   - *Обычные работающие сайты и крупные корпоративные франшизы автоматически исключены.*

## 🚀 Запуск веб-витрины (Next.js Showcase Portal)

Проект включает в себя полноценное веб-приложение на базе **Next.js 16 (Turbopack) + React 19 + Tailwind CSS**, визуализирующее всю собранную базу компаний с интерактивным каталогом и индивидуальными двуязычными лендингами под каждую бригаду (по аналогии с *All Florida Tree Care*).

```bash
# Установка зависимостей
pnpm install

# Запуск локального сервера разработки
pnpm dev
# Веб-приложение будет доступно по адресу http://localhost:3000

# Сборка статического продакшн-бандла (1197 сгенерированных страниц)
pnpm build
```

### Возможности портала
- **Главный интерактивный каталог (`/`):**
  - Живой мгновенный поиск по названиям, городам и штатам.
  - Фильтрация по 49 штатам США и типам проблем с сайтом (Missing Site, Connection Reset, Timeout, Facebook Page, SSL Invalid).
  - Карточки компаний с рейтингом, отзывами, статусом сайта, адресом, телефоном и прямыми ссылками на индивидуальные страницы.
- **Индивидуальные двуязычные лендинги:**
  - `/[slug]` — страница на английском языке (EN).
  - `/[slug]/ru` — страница на русском языке (RU).
  - Переключатель языков `[EN | RU]` и кнопка возврата в общий каталог `[← All Crews / ← Все бригады]`.
  - Честный расчет стоимости (интерактивный септик-калькулятор за 10 секунд).
  - Отработка 5 главных страхов клиентов (сохранность газона, видеодиагностика камерой перед копанием, отсутствие скрытых утилизационных сборов).
  - Витрина специализированной техники (вакуумные ассенизаторы, гидродинамическая промывка, телеинспекция труб).
  - Точный рейтинг с фракционными SVG-звездами и реальными отзывами клиентов из Google Maps.
  - Мобильная плавающая панель мгновенного звонка (`Emergency Call`).
